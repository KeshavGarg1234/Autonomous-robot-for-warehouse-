# Autonomous 4WD Robot | LiDAR-Based Navigation & Obstacle Avoidance

An autonomous 4-wheel robotic platform integrating **Raspberry Pi 4B, Arduino Mega, ESP8266, 2D LiDAR and ultrasonic sensors** to achieve intelligent movement, real-time obstacle detection and autonomous navigation.

The robot uses a 4WD skid-steer mechanism with independent motor control, multiple sensing systems and a distributed control architecture.

## Features

- **4WD Skid-Steer Drive:** Independent control of four DC motors for movement and in-place rotation.
- **LiDAR-Based Navigation:** RPLIDAR integration with Raspberry Pi for environmental scanning and navigation.
- **Ultrasonic Obstacle Detection:** Five HC-SR04 sensors for front, front-left, front-right, left and right obstacle detection.
- **Dual Sensor Fusion:** Combines LiDAR navigation with ultrasonic-based safety overrides.
- **Wireless Manual Control:** ESP8266-based web interface for remote operation.
- **Multiple Operating Modes:** Manual, Ultrasonic Autonomous, LiDAR Autonomous and Dual Fusion.
- **Intelligent Obstacle Avoidance:** Automatic reversing, turning and path clearance detection.
- **Communication Watchdog:** Stops the robot if navigation commands from Raspberry Pi are interrupted.
- **Modular Architecture:** Separate processing and control responsibilities for scalability and future upgrades.

## Hardware Components

| Component | Purpose |
|---|---|
| Raspberry Pi 4B (8GB) | Navigation and LiDAR processing |
| Arduino Mega 2560 | Motor and sensor control |
| ESP8266 | Wireless communication and web interface |
| RPLIDAR 2D | Environmental scanning |
| 5x HC-SR04 | Ultrasonic obstacle detection |
| 2x L298N | Motor drivers |
| 4x 12V DC Motors | Robot movement |
| 2x Servo Motors | Sensor positioning |

## Operating Modes

| Mode | Description |
|---|---|
| Manual | Wireless control through ESP8266 web interface |
| Ultrasonic Autonomous | Obstacle avoidance using five ultrasonic sensors |
| LiDAR Autonomous | Navigation commands generated by Raspberry Pi using LiDAR data |
| Dual Fusion | LiDAR navigation with ultrasonic safety overrides |

## Project Objective

The ultimate goal is to develop an intelligent autonomous mobile robot capable of understanding its surroundings, detecting obstacles, planning paths and navigating independently.

The platform is designed to support future integration of computer vision, SLAM, localization, artificial intelligence and advanced autonomous navigation algorithms.
